# Contributing

The contributing guide lives in the repository so it stays in step with the code:
**[CONTRIBUTING.md on GitHub](https://github.com/feagi/feagi/blob/staging/CONTRIBUTING.md)**.

It covers:

- Which FEAGI repository owns which part of the project
- Reporting bugs and proposing features
- Branching from `staging` and opening pull requests
- Development setup and the checks a pull request must pass, for Python and for the Rust core
- The design rules every change is reviewed against
- Security reports, community channels and licensing

Questions? Ask in [Discussions](https://github.com/feagi/feagi/discussions) or on
[Discord](https://discord.BrainsForRobots.com).
